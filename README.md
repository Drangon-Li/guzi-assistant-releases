# 谷子助手更新下载

此仓库用于分发谷子助手安装包和应用内更新清单，应用源码保存在独立的私有仓库中。

请从 [最新正式版本](https://github.com/Drangon-Li/guzi-assistant-releases/releases/latest) 下载适合设备的安装包。首次安装包含更新功能的版本后，可在软件的「设置 → 关于」中检查、下载并安装后续更新。

当前发布范围为 macOS Apple Silicon（arm64），最低系统版本以各版本发布说明为准。更新包使用 Sparkle Ed25519 签名；该签名与 Apple Developer ID 签名及公证不同，首次安装仍可能出现系统安全提示。
